---

## 🧩 Coding Standards (C++)

- Use `std::vector`, `std::unordered_map`, `std::priority_queue`
- Prefer **O(N)** / **O(N log N)** solutions
- Add **edge cases** & **time complexity** in comments
- Write readable function names
